# Poppys — site de hamburgueria

Landing page inspirada na referência enviada: cabeçalho escuro, hero fotográfico, cardápio em papel creme, bloco de combos, contato/mapa e rodapé vermelho. HTML, CSS e JavaScript estão separados.

## Abrir
Abra `index.html` no navegador. Para testar melhor, use uma extensão de servidor local no editor.

## Personalizar antes de publicar
- Substitua `assets/logo.jpg` pela logo oficial da Poppys, mantendo o mesmo nome.
- Em `script.js`, altere `whatsapp`, `phoneDisplay`, `address`, `hours` e `mapQuery`.
- Atualize nomes, descrições, fotos e preços dos produtos no `index.html`.
- Troque os links de Instagram/TikTok no rodapé pelos perfis oficiais.
- As fotos do cardápio são imagens ilustrativas hospedadas no Unsplash; substitua pelas fotos reais da Poppys.
- A localização atual é apenas demonstrativa (Correntina/BA) e deve ser conferida antes da publicação.

O botão de WhatsApp abre uma conversa com mensagem pré-preenchida. Para direcionar ao número da loja, preencha `whatsapp` com DDI + DDD + número, apenas dígitos.
